### Changed

- Renamed to gameWE: plugin `gamewe.smx`, include `gamewe.inc`, translations
  `gamewe.phrases.txt`, ConVars `gamewe_*`, server commands `gamewe_*`, natives
  `QueryGameWEStats` etc., forwards `onGameWEStats*`, library `gamewe`.
- Ported the whole code to current SourcePawn syntax (`#pragma newdecls required`).
  It compiles with the SourceMod 1.12 and 1.13 compilers without warnings, and the build treats
  warnings as errors.
- Typed handles (`ConVar`, `StringMap`, `ArrayList`, `ArrayStack`, `KeyValues`,
  `DataPack`, `Menu`, `Panel`, `Event`) instead of plain `Handle`.
- The game is detected from the engine version first, then by name as before.
- The TF2 sound hook uses the current SourceMod signature (`MAXPLAYERS` clients,
  sound entry and seed).
- The ConVars are written to `cfg/sourcemod/gamewe.cfg` (`AutoExecConfig`).
- The default list of hidden chat commands is a table instead of 150 single calls,
  and also covers `help` and the `gamewe_*` / `gameme_*` settings commands.
- License: GPL version 3 or later (the gameME plugin was GPL version 2 or later).
- Repository layout matches the install layout (`addons/sourcemod/...`), with a
  Makefile and a GitHub workflow that build `gamewe-sourcemod-<version>.tar.gz`
  and `.zip` for every commit on `main`; semantic-release makes the releases
  from Conventional Commits. The prebuilt `gameme.smx` is no longer in the repository.
- Chat commands: `/rank` is silent (the plugin logs it), `!rank` and `rank` stay
  visible (the engine logs them), menu entries are logged without a chat line and
  `gamewe_settings` is not logged. `gamewe_block_commands_values` adds commands.
- CS:GO: chat messages that start with a color code (prefix, damage summary,
  `gamewe_psay`, the messages of `gamewe_messages`) get a leading space, so
  CS:GO shows the color.
- CS:GO: `gamewe_khint` and the spectator info use the hint box: the Panorama
  HUD does not show key hints.
- CS:GO: `gamewe_browse` sends the URL as a chat line, as CS:GO shows no web
  pages in the MOTD panel.
- CI on Node 24 actions and `ubuntu-26.04` runners; SourceMod 1.12 and 1.13 are
  installed from sm.alliedmods.net. The release is built with SourceMod 1.12
  (stable), 1.13 is compiled as a check.

### Added

- `gameme_*` server commands, the gameME natives, the `onGameMEStats*` forwards and
  the `gameme` library stay registered, so collectors, scripts and plugins written
  for gameME keep working.
- `!gameme` and `!gameme_menu` open the menu as well as `!gamewe` and `!gamewe_menu`.
- CS:GO weapons for accuracy logging: `mp5sd`, `tagrenade`, `bumpmine`,
  `breachcharge`, `snowball`, `fists`, `axe`, `hammer`, `spanner`, `shield`,
  `knife_t` and the newer knives (`knife_ursus`, `knife_stiletto`, `knife_skeleton`, ...).
  Thrown items do not count as shots.
- Help texts for all server commands (`sm cmds gamewe`).
- `#assert` checks that every weapon list fits into the weapon statistics table.
- Settings menu: "Hide me in the ranking" / "Show me in the ranking" send
  `/gamewe_hideranking 1` / `0` for the player (collector 0.1.0 or newer). It
  opens with `!gamewe_settings` / `sm_gamewe_settings`, from the main menu
  ("Settings") and from SourceMod's `!settings` menu ("gameWE Settings").
  Translations for all languages.
- `hideranking`, `gamewe_hideranking 0|1` and `hideranking 0|1` are hidden chat
  triggers like the other commands.
- CLAUDE.md and security skills (security-check, release-security-gate,
  pre-commit-checklist); `INSTALLATION.md`.

### Security

- New ConVar `gamewe_chat_cooldown` (default `1.0`, 0-30 seconds): a player's
  silent `/` commands and menu entries are logged for the collector at most
  once per cooldown, so nobody can flood the collector and RCON with
  `/rank` or `/top10`. `0` turns it off. Commands the engine logs itself
  (`!rank`, `rank`) are not affected.
- `gamewe_protect_address` accepts only `IPv4:port` (port 1-65535); other values are
  rejected with an error and the ConVar is reset. Values with `;`, `"` or line breaks
  never reach `ServerCommand`, so the ConVar can no longer chain server commands.
- `logaddress_del` with several arguments could write past a buffer in the address
  protection; the arguments are now joined with `StrCat` and the real buffer size.
- `gamewe_browse` opens only `http://` and `https://` URLs (case-insensitive).

### Fixed

- Insurgency: weapons after position 64 of the 88-entry weapon list wrote outside
  the statistics array. The table now has room for 96 weapons.
- The reply commands (`gamewe_psay`, `gamewe_msay`, `gamewe_tsay`, `gamewe_hint`,
  `gamewe_khint`, `gamewe_redirect`) found the message by counting characters and
  only worked when the leading arguments were quoted in exactly one way. They now
  split the arguments properly, so `gamewe_psay 2 0 "text"` and
  `gamewe_psay "2" 0 "text"` both work. `gamewe_csay` also accepts unquoted text.
- Messages were used as format strings in `PrintToChat`, `PrintHintText` and
  `PrintCenterTextAll`, so a `%` in a player name or message broke the output.
- The forwards were created with a parameter list that did not match the calls
  (`Param_Array` instead of a by-reference handle), so they could not be called.
  They now match the include file.
- Query callbacks received the datapack by reference although the callback type
  takes it by value. They now get the handle itself.
- The example plugin read the country code into a 2-character buffer, which cut
  it to one letter.
- TF2: the "carrying a building" check walked the first `GetClientCount()` slots
  instead of all client slots.
- CS:GO clan tag logging used the result of `KvGetString`, which returns nothing,
  so the check was undefined. Newer compilers reject this.
- Polish translation: missing closing quote in the menu title.
- `gamewe_messages`: a player name with `%` in it broke the chat message (it
  was used as the format string).

### Removed

- ConVar `gameme_webpage`.
- Optional natives of the socket extension, which the plugin never used.
- ConVar `gamewe_block_commands` (the chat behaviour is fixed, see above). A
  `gamewe_block_commands` line in an existing `gamewe.cfg` is ignored.
- The gameME menu entries "Auto Ranking" (with its submenu, `/gamewe_auto ...`),
  "Toggle Ranking Display" (`/gamewe_hideranking`) and "Reset Statistics"
  (`/gamewe_reset`) and their translations: the collector does not answer them.
  The commands stay on the hidden-trigger list.
